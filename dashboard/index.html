PR Guardian transforms AI from a manual "copy-paste chatbot" into an autonomous engineering teammate that participates natively in GitHub code reviews. 

  +-----------------------------------------------------------------------------------+
  |                                 DEVELOPER WORKFLOW                                |
  |                                                                                   |
  |  1. Developer pushes code to feature branch & opens GitHub Pull Request          |
  +-----------------------------------------+-----------------------------------------+
                                            |
                                            v
  +-----------------------------------------------------------------------------------+
  |                        GITHUB ACTIONS CI/CD TRIGGER                               |
  |                                                                                   |
  |  - Event: pull_request [opened, reopened, synchronize]                            |
  |  - Concurrency group cancels obsolete runs when new commits arrive                |
  |  - Least-privilege permissions: pull-requests: write, issues: write, contents: read|
  +-----------------------------------------+-----------------------------------------+
                                            |
                                            v
  +-----------------------------------------------------------------------------------+
  |                           PR GUARDIAN DIFF EXTRACTION                             |
  |                                                                                   |
  |  - Retrieves ONLY changed files & patch hunks (not the whole repository)          |
  |  - Ignores package-lock.json, binary files, minified bundles, deleted files       |
  |  - Computes valid '+' line anchors to ensure GitHub API 422 errors never occur    |
  +-----------------------------------------+-----------------------------------------+
                                            |
                                            v
  +-----------------------------------------------------------------------------------+
  |                      GOOGLE GEMINI STRUCTURED ANALYSIS                            |
  |                                                                                   |
  |  - Model: Google Gemini 2.5 Flash (configurable via GEMINI_MODEL)                |
  |  - Strict JSON schema: summary, findings (CRITICAL/HIGH/MED/LOW, BUG/SEC/PERF/QLTY)|
  |  - Automated retry with exponential backoff on transient errors                   |
  +-----------------------------------------+-----------------------------------------+
                                            |
                                            v
  +-----------------------------------------------------------------------------------+
  |                    FINGERPRINTING & DEDUPLICATION ENGINE                          |
  |                                                                                   |
  |  - Generates SHA-256 fingerprint from: file + category + title + explanation      |
  |  - Compares against existing comments on PR                                       |
  |  - New issues -> posted inline. Unchanged existing issues -> skipped (NO SPAM!)   |
  +-----------------------------------------+-----------------------------------------+
                                            |
                                            v
  +-----------------------------------------------------------------------------------+
  |                             GITHUB PR NOTIFICATION                                |
  |                                                                                   |
  |  - Detailed inline review comments attached directly to the offending line        |
  |  - Exactly ONE top-level summary comment updated across all commit cycles         |
  +-----------------------------------------------------------------------------------+
